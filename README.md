A warning about signing away a family home in grief, and the cost Mom carries afterward. An original two-line entry for make.fun, written in this session.

## Run it

Requires Node 22.18 or newer; no dependencies.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program validates its literal text and writes only `entry.txt` into the output directory. It uses `MAKEFUN_OUTPUT_DIR`, defaulting to `/output`.

## Entry

> Don't sign the papers beside Dad's funeral flowers on the kitchen table.  
> You sold the house he built for half its worth, and by Christmas Mom was knocking at the front door with her old key still on her ring.
